# SelectAI

Instant AI actions on any selected text.

A lightweight macOS menu-bar app that lets you search, translate, ask AI, and look up words from any selected text — instantly.

## Download

Get the latest release from the [Releases page](https://github.com/shyn/selectai.app/releases/latest).

Requires macOS 14.0 or later · Apple Silicon

## Features

- **Ask AI** — Send selected text to any OpenAI-compatible API
- **Quick Search** — Search with Google, DuckDuckGo, or Bing
- **Dictionary** — Look up word definitions instantly
- **Translation** — Translate between 12 languages
- **Smart Copy** — Copy text from any app with one click
- **Vocabulary Builder** — Save words as you read

## How It Works

1. Select text anywhere on your Mac
2. A floating toolbar appears next to your selection
3. Click an action — results appear inline, no context switching

## Auto-Updates

SelectAI uses [Sparkle](https://sparkle-project.org) for automatic updates.
